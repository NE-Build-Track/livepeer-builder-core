## Later on 12 October: runtime findings

1. **T9: SDK #71 and livepeer/node.** The SDK reads go-livepeer's `"State"` key; node returns `"state"`,
   so `auth_ids` come back empty. With a one-line, container-only fix, reconciliation balanced exactly
   against Batteries ([evidence](../references/evidence/2026-10-12-dev-stack-paid-run.md)).
2. **T10: the node signer and public orchestrators.** All four public orchestrators tested use a node
   key different from their registered ticket recipient (a hot/cold split that go-livepeer allows).
   The node signer requires them to be equal, so no paid job could be sent. The fix options are being
   decided with Mike: an upstream change to node (recommended), or a dev-only signer patch to prove the
   path.
