# M4 decisions

Accepted decisions for M4, reuse and reliability ([m3-decisions](m3-decisions.md) holds D29–D63). Each
row was locked by Mike in the question-by-question review of 12 and 13 November 2026. A row names the
earlier decision it amends. The detail of each answer is in the linked guide's "Questions locked" section,
or in the linked ticket.

D82 to D87 were locked by Mike on 18 November 2026. They replace D74 with the payment clearinghouse and
amend D71, D72, D75 and D77, as each row says. D87 settles the points that D85 and the guides had left
for John.

## Direct signer amendment (19 November 2026, John)

For the comparison change to PR #180, D85(1) and D87(1,3) are superseded: the work engine owns
allocation API credentials and calls the signer directly. The clearinghouse exposes no signer proxy,
issues no second payment credential, and persists no allocation secret. It delivers the provider
credential once through authenticated allotment/rotation. Batteries management stays private.
Completed retries return metadata only; a lost credential is recovered through explicit rotation.
P5 defines the handoff; P6 supplies listeners, P7 the remote adapters and work-engine persistence,
and P8 role selection and deployment wiring, in the existing stack order.
